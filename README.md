# 第258回 鹿児島県スイミングクラブ水泳競技大会（チャレンジ大会） エントリー確認

- 鹿児島県水泳連盟HPに掲載された「エントリー確認（申込一覧）」（2026-10-15 発行）をもとにした、非公式のエントリー確認アプリです。
- 233名・個人443件・リレー19チーム（18チーム）。大会は 2026-11-08（日）鴨池公園プール。
- `entries.tsv`（個人。1行＝1種目）と `relays.tsv` は、申込一覧PDFの文字情報を位置どおりに読み取って作成しました。
  - 列：登録No. / 氏名 / よみ / 所属 / 所属よみ / 学年 / 年齢 / 性別 / 泳法 / 距離 / 区分（1幼稚園生 2:8才以下 3:9〜10才 4:11才以上） / エントリータイム
  - 板キック・背面キックは申込一覧で「200m」と表示されている（自由形の欄＝板キック、背泳ぎの欄＝背面キック）。`build.py` で 25m に読み替えています。
  - 性別は申込一覧に欄がないので、チームごとの並び（男子→女子、それぞれ年齢の高い順）から判断しました。
    並びで切り替わりが見えないチームの No.106 松永 史織・No.108 萩原永実理・No.170 山崎 歓乃 は名前から「女」としています。
- `python3 build.py` で `template.html` と2つのTSVから `index.html` を作り直します。
- 公開は `258th-Kagoshima-SC-Challenge-Swim-Entries` リポジトリの `gh-pages` ブランチから行います（`index.html` だけあれば動きます）。
